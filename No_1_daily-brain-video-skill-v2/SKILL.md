# 每日脑力挑战视频 Skill 2.0

## 先读此约束

- 先读 `references/完整题型分类与玩法.md` 或可解析的 `references/完整题型库.json`；它有 **16类、98种**视频玩法及建议时长。
- **不要再固定只轮换3种题型**，新系列先做多样化排期。用户明确要求某一类别、期数、时长、视频无答案等优先执行。
- 任何“科学训练”“强化前额叶”“提高智商”“治疗注意力障碍”的显著因果效果均不能无依据保证。栏目名可以叫“前额叶训练”，具体说明用“脑力小游戏”“视觉搜索”“工作记忆练习”等。
- 用户已有偏好：竖屏9:16、深蓝黑科技风、原创建议音效、默认**不公开答案**、视频末尾邀请评论成绩；数字类可90秒，非数字类按实际玩法安排30–120秒。**不要为所有玩法强行套90秒。**
- 文生图不作为数字排布和答案唯一性的权威；程序确定题目数据，再制作可视化，结束时校验。

## 1. 精确理解任务

- “第N期”：编号为N，用户说了类型就优先该类型。
- “下一期”：基于对话最近成片编号加1，不根据日期猜编号。
- “帮我做30天排期”：执行 `python scripts/plan_series.py --start-day 4 --days 30 --output-dir /mnt/data/brain_plan`。规划器跨16类别轮换，输出30天题型、难度、时长、镜头结构。仅为**计划与脚本**，不是30条自动渲染视频。
- “帮我做新视频”：先在完整题型库中选一个适配高的模板，再明确是否已有程序支持。若没有程序可生成该玩法，需开发并测试该玩法模板，完成视频才可说已出片；否则只能交付计划、脚本和素材，不能冒称成片。

## 2. 一期视频应包含

1. 游戏名称与期数；2–5秒前导：观众要做什么。
2. 规则与示例（必要时）；避免中途改不清楚的规则。
3. 任务画面：按玩法合理安排倒计时（数字搜索可90秒，Stroop 40–60秒，记忆观察/答题分段，逻辑题45–90秒）。
4. 最后3–7秒显示“你完成了吗？留言成绩”，**不公布答案**。
5. Creator-only 答案及质检记录；与观众版本分开放置。
6. 输出：题面、分镜脚本、配音文案、字幕SRT、发布文案、封面；有能力渲染则给出MP4和ZIP。

## 3. 难度升级

- 基础：单目标、低干扰、20–30条刺激、宽松计时。
- 进阶：更多刺激、不规则布局、目标条件组合、计时缩短、加干扰。
- 高难：动态追踪、双规则、工作记忆更新、部分遮挡、视觉+听觉双通道等。
- 保证数字和文字清晰、难度合理、观众明白规则；不可用几乎看不清的字造难度。

## 4. 已实现的自动生成器（3个）

现有 `scripts/generate.py` 支持 `--type disc|balls|memory`，分别对应旋转圆盘、动态小球、12物品位置记忆。

```bash
python -m pip install -r requirements.txt
python scripts/generate.py --day 4 --preview --output-dir /mnt/data/test_day04
python scripts/generate.py --day 4 --output-dir /mnt/data/DAY04
```

视频生成依赖 FFmpeg 和可用中文字体。`--type auto` 保留旧版3种自动循环，**不能**代表已支持16类别；若要拍摄全类别系列请先使用规划器，再为未支持的题型开发可控动画。

## 5. 已实现的选题规划器（16类）

```bash
python scripts/plan_series.py --start-day 4 --days 30 --output-dir /mnt/data/brain_plan
```

写出 `30天选题计划.csv`、`30天选题计划.md`、`30天选题计划.json`。30天轮换覆盖16大类，避免两天连续同类。优先直接互动(A)和多元化，保留个别B类。输出标明每题 **已有视频渲染模板 / 需要新增模板**。

## 6. 创作者交付前质检

- 目标数量与规则完全匹配：数字1–N各出现一次或满足题目的唯一性约束。
- 记忆题答案、图片位置以及配音指令一致；逻辑题必须独立验算，确保正确答案唯一（除非明确开放题）。
- 对Stroop/Flanker/N-back/Go-No-Go等经典范式，严格按规则生成刺激序列，若设计学习型变体需明确标注非标准测试。
- 题目持续时间、倒计时、帧序与字幕音频同步，无黑屏和字体溢出。
- 面向观众的任何画面/封面/字幕/音频均不泄露答案；创作者答案单独保存。
- 真实核对输出文件才允许给用户 `sandbox:` 链接，不推断或编造文件路径。
