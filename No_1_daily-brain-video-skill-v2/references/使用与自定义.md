# 技能使用与自定义细则

## 环境

- Python 3.10+；`pip install -r requirements.txt`
- `ffmpeg` 和 `ffprobe` 可从命令行调用。
- 字体：推荐 Noto Sans CJK。可设置 `BRAIN_FONT_BOLD`、`BRAIN_FONT_REGULAR` 环境变量，分别指向本机的中文粗体和常规字体文件。不要把商业字体文件打包传播。

## 运行命令

`python scripts/generate.py --help` 查看所有参数。

- `--day N`：期数；默认按3天轮换。
- `--type auto|disc|balls|memory`：强制指定类型。
- `--seed 1234`：同一个种子可以重现相同的数字排布或记忆物品排列。
- `--challenge-seconds 90`：仅对数字搜索有效；记忆题有固定的观察与答题阶段。
- `--fps 12`：正式视频帧率。要更流畅可提高，渲染也会更慢。
- `--preview`：快速检查，540×960且缩短时长。
- `--no-video`：只生成题面、脚本和质检数据。
- `--memory-tiles-dir PATH`：指定自己的12张记忆物品素材目录。
- `--output-dir PATH`：输出文件目录。

## 如何更新短时记忆题素材

目录需要包含 `manifest.json` 与12张PNG/JPG文件：

```json
{
  "items": [
    {"name": "小熊", "file": "01.png", "category": "object"},
    {"name": "苹果", "file": "02.png", "category": "fruit"}
  ]
}
```

这里只展示前2项，实际必须恰好12项、名称不重复、图片路径有效。`category` 为 `fruit` 的条目计入“几种水果”问题。每张图片应只包含一件清晰物品，比例建议4:3或接近。AI生成图片后**逐张检查**物品是否与名称一致，避免题目与答案不符。

脚本自动打乱12个位置并生成3道题：指定物品的位置、某个位置的物品、画面里的水果种类数量。正确答案仅写入 `创作者专用_答案.json`。

## 自动化质量检查

1. **数字完整性**：必须恰好49个数字，集合等于 `{1,...,49}`；生成器内有断言，`生成参数_质检.json` 也会记录通过状态。
2. **记忆题**：每题选项中只有一个正确答案；生成器内校验并输出创作者专用答案。
3. **画面**：预览封面与至少三个时刻的截图（开头、挑战中间、片尾），检查文字、数字和图形没有遮挡或重叠。
4. **时间**：数字题正式版99秒；记忆题63秒。若自定义时长，以生成参数为准。使用 ffprobe 验证。
5. **无答案**：所有公开视频画面、字幕与音效不能泄露正确答案。私有答案JSON不要发布。
6. **交付**：成片MP4、封面PNG、脚本Markdown、字幕SRT、音效WAV、素材ZIP都要实际存在；失败时不要伪称完成。

## AI协作提示词

> 你是我的“每日专注力挑战视频生成器”。请按我现有系列风格制作 Day N：三天轮换动态圆盘舒尔特、动态小球舒尔特、短时记忆挑战。数字题90秒找完1–49，记忆题20秒观察后答3题；统一9:16深色科技风、倒计时、原创提示音、无答案揭晓。请先生成可校验的题目，再生成成片、封面、脚本、字幕和创作者素材包，检查数字唯一性、题目正确性、时长及清晰度。没有成功生成的文件不要给下载链接。

## 科学表达

推荐使用“专注力挑战”“视觉搜索游戏”“短时记忆小游戏”等名称；“前额叶训练”可以作为系列化栏目标题，但不应承诺能改善脑功能或治疗疾病。
