# 中文美食图解 + 文案生成 Skill 双件套

这是一套从原始菜谱到成品图片、再到社交平台文案的可复用工作流。

## 包含两个独立 Skill

1. `chinese-recipe-poster` —— 将中文菜谱生成“成品主图 + 用料配比 + 编号制作步骤 + 小贴士”的美食信息图。包含图解设计规范与海报风格参考小图。
2. `chinese-food-social-copy` —— 将同一菜谱生成可复制的中文小红书/抖音/朋友圈发布文案，优先保持原配比与步骤准确。

每个 Skill 都有自己的 `SKILL.md`，符合 Agent Skills 的基本目录结构。两个文件夹可以**分别**导入支持 Skill 的产品；整个合集压缩包主要用于备份和分享，不一定能当成“单个 Skill”直接导入。

## 建议顺序

输入菜名、配比、做法与提醒 → `chinese-recipe-poster` 生成菜谱海报 → `chinese-food-social-copy` 使用**原始菜谱**生成文案。

## 典型提问

- “用这份食谱按之前的橙白绿风格生成菜谱步骤图片。”
- “把刚才的菜谱写成一段小红书发布文案，带配比、步骤和话题标签。”
- “先做菜谱海报，再配一段文案；配料克数必须一致。”

## 安装或使用

- 如果你当前使用的 ChatGPT / Codex 入口支持导入 Skill，按该入口提示上传**每个 Skill 的独立 zip 包**。
- 若没有 Skill 上传入口，可以直接打开并复制对应 `SKILL.md` 的内容，用作自定义指令或在新的对话中粘贴执行。
- 图片 Skill 只有在使用环境具备图像生成工具时，才会直接生成图片；否则只能给出准确的制图提示词。

## 设计原则

原始菜谱是唯一的事实基准；生成图片的文字可能不完全准确，因此文案不从图片反推数量；每次检查原料克数、步骤和熟度提醒。
